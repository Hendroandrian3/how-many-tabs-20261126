One number, digits only: the honest count of open browser tabs. The most
surprising count wins.

## The number

> 847

Three digits, odd and specific — the count of a real tab hoarder, not a round
number picked to shock. Eight hundred and forty-seven tabs across a few
windows: research that was never closed, docs left open "just in case",
articles saved by leaving them open, and the tabs that have been there so
long nobody remembers why. High enough to surprise, believable enough to be
a lived-in answer.

## Run

```sh
node main.ts
```

Writes the number to `/output/entry.txt`. Deterministic: the number is a
fixed string, so every run writes identical bytes.
